# Этап 3: версионированный контракт

Статус: в разработке и проверке.

Область изменений ограничена репозиторием СОЙКА UDS Development. Репозиторий Geo Analyzer 2 и работающий SaaS-сервис не изменяются.

Критерии завершения:

- контракт версии `1.0.0` опубликован как JSON Schema;
- Python-модели строго проверяют request, status и result;
- реализованы fingerprint и контроль идемпотентности;
- структурированные ошибки, coverage и частичный результат протестированы;
- схемы экспортируются из установленного пакета;
- полный CI завершён успешно;
- PR объединён с `main`.
