# Этап 3: версионированный контракт

Статус: выполнен 5 августа 2026 года.

Область изменений ограничена репозиторием СОЙКА UDS Development. Репозиторий Geo Analyzer 2 и работающий SaaS-сервис не изменялись.

Выполнено:

- опубликован транспортно-независимый контракт версии `1.0.0`;
- добавлены строгие Python-модели request, status и result;
- опубликован комплект JSON Schema Draft 2020-12;
- реализованы fingerprint и контроль идемпотентности;
- реализованы структурированные ошибки и предупреждения;
- определены coverage и частичный результат;
- добавлен provenance с версиями СОЙКИ, моделей и алгоритмов;
- схемы экспортируются из установленного пакета;
- добавлены CLI-команды просмотра, экспорта и проверки документов;
- добавлены примеры всех публичных документов;
- добавлены unit- и contract-тесты;
- восстановлен постоянный CI без временной логики и прав записи.

Проверка:

- Python 3.11 compilation — успешно;
- Ruff — успешно;
- 36 детерминированных unit- и contract-тестов — успешно;
- проверка `poetry.lock` — успешно;
- сборка и запуск CPU-контейнера — успешно;
- `/healthz` и `/readyz` — успешно;
- сборка GPU Docker target — успешно.

Подключение работающего Geo Analyzer 2 к этому контракту выполняется отдельным этапом и не входит в этап 3.
