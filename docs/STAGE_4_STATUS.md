# Этап 4: оркестратор полного процесса

Статус: реализован, проходит проверку.

Область изменений ограничена репозиторием СОЙКА UDS Development. Репозиторий Geo Analyzer 2 и работающий сервис не изменяются.

Реализовано:

- конечный автомат из восьми стадий;
- checkpoint после каждой стадии;
- атомарное JSON-хранилище;
- optimistic locking по revision;
- межпроцессные file locks;
- идемпотентная регистрация задания;
- worker lease и восстановление после истечения lease;
- контролируемые повторы с exponential backoff;
- постоянные и повторяемые структурированные ошибки;
- отмена между стадиями;
- явный retry failed-задания;
- запрет неструктурированных результатов и `DataFrame` между подсистемами;
- материализация `AnalysisResultV1`;
- CLI для list, status, cancel и retry;
- unit-, recovery-, failure-injection- и CLI-тесты;
- исходный код нормализован по постоянным правилам Ruff проекта.

Критерий завершения: после аварийного завершения worker новый worker продолжает выполнение с последнего подтверждённого checkpoint, не повторяя завершённые стадии.
