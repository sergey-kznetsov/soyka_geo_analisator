# Этап 6A: подготовка коннекторов

Статус: выполнен 5 августа 2026 года.

Область изменений ограничена репозиторием СОЙКА UDS Development. Geo Analyzer 2 не изменялся.

Результат:

- создан типизированный контракт connector blueprint;
- создан каталог российского периметра;
- подготовлены VK, OK, local media, municipal public, Дзен, Пикабу и RUTUBE;
- YouTube не включён;
- все коннекторы отключены от сети;
- зафиксирован free-first режим;
- автоматический paid fallback запрещён;
- API credentials должны предоставляться владельцем развёртывания;
- локальные СМИ и муниципальные сайты получают отдельный HTML site profile;
- HTML site profile ограничен HTTPS, доменом, регионом и муниципалитетами;
- JavaScript rendering требует отдельного обоснования;
- добавлены JSON Schema и конфигурационные шаблоны;
- добавлены детерминированные unit-тесты без сети;
- закреплена архитектура одного удалённого сервера с логической изоляцией модулей.

Проверка materialization:

- SHA-256 всех частей и итогового архива — успешно;
- Ruff — успешно;
- форматирование Ruff — успешно;
- Python 3.11 compilation — успешно;
- 27 изолированных connector preparation tests — успешно.

На этом этапе определения не реализуют `ParserAdapter` и не регистрируются в `ParserRunner`. Это выполняется на этапе 6B вместе с integration tests.
