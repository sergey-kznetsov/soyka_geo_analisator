# Этап 6B: адаптеры приоритетных источников

Статус: реализован и проходит проверку.

Область изменений ограничена репозиторием СОЙКА UDS Development. Geo Analyzer 2 не изменяется.

## Реализованные адаптеры

- `VkApiAdapter` — официальный VK API: публикации со стен сообществ и комментарии;
- `OkApiAdapter` — официальный API Одноклассников: комментарии дискуссий;
- `HtmlConnectorAdapter` — разрешённые HTML, RSS/Atom и sitemap для локальных СМИ, муниципальных источников, Дзен, Pikabu и RUTUBE;
- `OkMd5Signer` — изолированное формирование подписи API без передачи secret в `ParserRequest`;
- `build_prepared_parser_registry` — регистрация всех подготовленных адаптеров в существующем `ParserRegistry`;
- интеграция со штатным `ParserRunner`, checkpoint, retry, дедупликацией, privacy-фильтрами, coverage и audit платформы этапа 5.

## Архитектурные правила

VK и Одноклассники остаются API-only. Публичный HTML этих платформ не используется production-адаптерами как скрытая замена официального API.

Секреты не передаются через `ParserRequest` и не сохраняются в checkpoint. VK использует credential provider безопасного транспорта. OK получает signer, созданный серверным composition root из secret storage.

HTML-коннектор:

- выполняет только HTTPS GET через `ParserServices.transport`;
- остаётся в доменной allowlist политики;
- не выполняет JavaScript;
- поддерживает ограниченный проверяемый набор CSS-селекторов;
- разбирает HTML-страницы, RSS/Atom и sitemap;
- использует очередь URL в opaque checkpoint;
- возвращает только `SourceMessage`;
- не классифицирует, не геокодирует и не изменяет Geo Analyzer.

## Тестовые контуры

1. Fixture-based unit tests проверяют mapping, timestamp, stable external ID, checkpoint и ошибки источника.
2. Integration test регистрирует все семь адаптеров и запускает их через `ParserRunner` с mock HTTP transport.
3. Controlled external probe делает не более одного GET на источник и сохраняет только HTTP-метаданные и короткий извлечённый фрагмент. Это не production collection и не заменяет credentials, permission или review.
4. Controlled external probe считается успешным только когда каждый источник вернул HTTP-ответ. Отказ авторизации, CAPTCHA или anti-bot фиксируется как диагностический результат без обхода ограничения.

## Ограничения

Реальный сбор VK и OK требует действующих credentials приложения и разрешённой сессии. Официальная документация OK указывает обязательные параметры приложения и подпись, а получение комментариев дискуссии требует сессии и права `VALUABLE_ACCESS`.

Профили конкретных СМИ и муниципальных сайтов должны пройти отдельную правовую, robots и selector-проверку перед переводом политики в `approved + enabled`.

## Критерий завершения

- все семь адаптеров зарегистрированы без изменения аналитического ядра;
- fixture suite получает минимум одно сообщение от каждого источника;
- полный CI и Docker-контур зелёные;
- controlled external probe выполнен и сохранён;
- результаты и ограничения каждого источника отражены без имитации успешного live-сбора.
